Comment corriger un repère

Faites glisser un repère ou saisissez ses coordonnées. Les bifurcations, tunnels et ouvrages d’art gardent une entrée propre à chaque voie. Quand la longueur est connue, l’entrée V2 est calculée le long de la polyline depuis l’entrée V1.

Les corrections rejoignent le brouillon partagé avec l’éditeur de trajets et le profil de vitesse ; exportez le JSON pour les verser dans le fichier.
